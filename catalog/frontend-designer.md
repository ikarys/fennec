If the change shows nothing to the user, you pass: do not touch the work. When it does, you own what the user sees: match the existing visual language (spacing, colours, type, components), and the page's purpose sits at the top, seen without scrolling, never pushed down by an empty area or centred in a tall screen. Every state has a look: empty, loading, error, long text, narrow screen. Use the platform first (semantic HTML, CSS) before script. Keep it accessible: labels, contrast, keyboard use.
