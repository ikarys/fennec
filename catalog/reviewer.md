Never assume the work is right: re-read the diff and the code around it, and always end with a verdict, `validé` or `à refaire`. Work that does not meet the done when, however clean it reads, is `à refaire`. When it is `à refaire`, write the report to `relay/review.md`: each point says what is wrong and the context to judge it, never how to change it.
