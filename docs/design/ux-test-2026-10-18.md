# UX test — 2026-10-18

Driven like a human: Playwright + headless Chromium (1440×900) on the live
instance (`127.0.0.1:7777`), clicking and typing only. Scratch project
`~/workspace/ux-todo`, three real requests (a todo list, then filters, then a
dark mode). Five use cases, set by the user.

| Use case | Verdict |
|---|---|
| 1. Create a project, configure it, start working | partial |
| 2. See what runs, what was done, cost, failures | there, but flat |
| 3. Control what was done | good, one real bug |
| 4. Use skills | missing |
| 5. Work on one project without the others in view | missing → **fixed** |

## 1. New project

- **No way to create a folder from the UI.** "+ projet" only browses existing
  folders; the user has to leave for a terminal to `mkdir`.
- The dialog is titled "Choisir un projet" though it adds one; it opens on
  `/home/tony` with "Ajouter ce dossier" already enabled — one stray click
  makes the home folder a project.
- No confirmation, no project page after creation; only the select changes.
- **Configuring = the team only.** Rules (`AGENTS.md` `## Rules`,
  `~/.config/fennec/rules.md`) are given to every agent but can be neither read
  nor edited anywhere. "Where fennec works" lives in the **Stats** dialog,
  where nobody looks for a setting.
- Good: request to ready in ~45 s, no question asked.

## 2. Seeing what happens

- The live journal of a running request is good (steps, roles, tokens, tool
  calls as they happen).
- **Collapsed, a running line says only "travaille" / "essaie le produit"**:
  no elapsed time, no "step n of m". After "Réessayer" it shows the previous
  try's stale figures (⏱ 3 s).
- The live journal shows the raw English system prompt ("Consigne You help
  a person…"). Audit material; should be folded by default.
- Stats is a modal (cannot watch work while reading it), all projects mixed,
  no period (today / this week), no *why* behind failures.
- ⏱ 🔒 🏠 📖 render as empty boxes in headless Chromium (font missing there;
  check on a real desktop).

## 3. Control

- Good: diff in a scrolled box, "Corriger" opens a field in the card,
  "Non vérifié — à regarder toi-même".
- **Bug: commit target was the request's own work branch.** Commit "filters",
  then "Réessayer" on "dark mode" at once: the card offered
  **"Commit dans world/6ad46668416b9"**. Cause: `solve::plan` lets the model
  pick the branch from the `Branches` list, which included `world/*`. Also
  leaks an internal name (rule 2). **Fixed** in fennec-os (world branches are
  neither shown to the model nor accepted from it).
- **A second request on a project in "Dans le dossier" mode fails at once**
  instead of waiting its turn; the failed card's primary button is
  "Réessayer", which fails again while the first one runs. **Fixed**: it
  waits its turn under "fennec travaille" ("attend son tour : « X » occupe le
  dossier", or the human's uncommitted changes), starts by itself once the
  folder is free, and keeps waiting across a restart of fennec.
- **First proof was worthless**: fennec added a task then deleted it, so
  "Avant" and "Après" were identical — yet the card said **PRÊT** in green.
  (The filters proof was convincing.)
- "Ce que fennec a fait" is one block: Markdown lists collapsed onto one line,
  `**HTML**` shown raw. "Terminé quand" repeats the request before saying when.
- The ready card is ~1500 px tall: 6 buttons + 1 link, "Commit" alone on a
  second row at the very bottom.
- Missing **"Ouvrir la page"**: for a web project the human wants to try the
  result, not only open the code.
- Commit messages read "fennec-os: Créer …": French, not Conventional Commits.

## 4. Skills

Nothing in fennec-lead or fennec-os knows the notion (`grep skill` is empty):
no catalogue, no choice per project or request, no trace in the journal of
which skill was used. Teams are close but they are roles, not reusable
know-how.

## 5. One project at a time — fixed

Before: history mixed every project; the select only chose where the *next*
request goes; a reload reset it to "Quel projet ?".

Now: the select is the focus. Picking a project shows only its requests (the
project name leaves each line), the address keeps it (`#<path>`, reload and
bookmark come back to it), the tab title names it, and "N autres t'attendent
ailleurs" next to "À toi" says what waits in other projects — one click goes
back to "Tous les projets".

## Layout

Everything sits in a ~950 px column in the middle of a 1440 px screen, with
modals on top. Proposed: a sidebar of projects, a page per project, "À toi"
across projects with the filter above. Proof screenshots should be cropped to
the page itself (~60 % of each picture is grey background).
